# Security Policy

## Supported Versions

Security updates are provided for the latest released version of Azure AI Search Simulator. Older versions are not supported; please upgrade to the latest release before reporting an issue.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Report suspected vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/Ellerbach/azure-ai-search-simulator/security/advisories/new). Include:

- A description of the vulnerability and its potential impact
- The affected version and configuration
- Steps or a minimal example to reproduce the issue
- Any known mitigations or workarounds

Please allow the maintainers time to investigate before disclosing the vulnerability publicly. You will receive updates through the GitHub security advisory as the report is assessed and addressed.
